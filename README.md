# Sales Management System

A desktop application for managing sales operations. The original source is intended to be reviewed and modernized in follow-up commits.

## Technology

- C# / Windows Forms

## Project status

Initial repository setup. Source code review, dependency verification, security cleanup, and setup documentation are pending.

## Getting started

Please review the source files and configure local environment values before running the application. Never commit passwords, API keys, private credentials, or real user/patient data.

## Security

- Keep secrets in local environment configuration, not in version control.
- Use sample or anonymized data only.
- Review database exports and uploaded files before publishing.
